1. Exact Anatomy of the Competition Metric (Distance-Weighted Tversky Index)

Let P be the set of predicted fault pixels (for binary dot submissions, |P| = N_P) and G be the hidden ground-truth fault pixel set (containing both the 60,988 mapped catalogue pixels G_cat and hidden unmapped fault pixels G_hid). With triangular buffer kernel w(d) = max(0, 1 - d / 3.0) (where d is Euclidean distance in 100 m pixels, radius R = 300 m = 3 px) and Tversky weights α = 0.2 (false-positive weight), β = 0.8 (false-negative weight), the Distance-Weighted Tversky Index is:

TP_w(P, G) = Σ_{q ∈ G} w(d(q, P)),    FP_w(P, G) = Σ_{p ∈ P} [1 - w(d(p, G))],    FN_w(P, G) = |G| - TP_w(P, G)

DTI(P, G) = TP_w / (TP_w + 0.2 · FP_w + 0.8 · FN_w)

Notice the critical identity when emitted dots lie outside the 3-pixel kernel of most hidden faults: each emitted dot p ∈ P adds 0.2 · (1 - w(d(p, G))) ≈ 0.2 to the denominator. Adding a new dot p increases the overall DTI score S if and only if its marginal weighted true-positive coverage ΔTP_w(p) exceeds the break-even threshold:

τ(S) = α · S / [1 - (β - α) · S] ≈ 0.2 · S    (τ = 0.05556 at S = 0.2778)
