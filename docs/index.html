Three steps to a file

  1. Place the data (once, on your own machine): bash scripts/download_competition_data.sh, then add the DrivenData files by hand.
  2. Check it: python scripts/prepare_data.py
  3. Make and validate the file: python scripts/make_submission.py --name <name> --note "<note>", then python scripts/validate_submission.py submissions/<name>.tif --template data/example_submission.tif

What the holdout must beat

A trivial map that predicts "fault" everywhere reaches about 0.24 on a sparse synthetic fault network under our metric, and beats 0.2778 whenever the real mean tolerance coverage is at least 7.1%. Any model must beat that trivial baseline on the same holdout, with a confidence interval that excludes it. See RESEARCH §1.

Core values

Maximize P(Win). Weigh every trade-off, assess risk, and pick the path most likely to succeed.

Own the Outcome. Treat failure and success as signals. Flag problems rather than hiding them.

Every number on this site is labelled HOLDOUT-DTI, ORGANIZER-CONFIRMED, USER-REPORTED, or a projection. Projections are never written as scores.
